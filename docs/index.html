Can a small router learn where relevant answers live—without changing the embedding model?

Question→ Frozen BGE-small→ Region probabilities→ Search selected regions

Fine-tuning an embedding model can improve domain alignment, but changes to document representations can also require encoding and indexing the corpus again. This experiment learns a small query-to-region model over an unchanged answer index. High routing accuracy only matters if it searches substantially less of the corpus.

Searching every region gives perfect region coverage by construction. It is the no-pruning endpoint, not a routing success. Learned probabilities use supervision; nearest-centroid routing uses only frozen geometry.

What the probabilities mean

The training target is the region containing a uniformly drawn labeled relevant answer. Several answer regions can receive probability mass for the same question. The router is a 64-unit residual MLP on top of centroid similarities. Top-probability routing and stochastic sampling use the same trained model; sampling uses distinct regions without replacement.

The corpus is partitioned using document-only spherical k-means. Inside selected regions, answers are ranked by cosine similarity with the unchanged question embedding. A router can recover a missed neighborhood, but it cannot repair the order of answers within that neighborhood.

A benchmark, with a clearly defined adaptation

WikiQA provides questions, candidate answer sentences, and relevance labels. We preserve its official question splits and exclude questions with no labeled positive from this answer-location task. All unique answer sentences form one searchable corpus. This is an adapted global retrieval task, not the official candidate-restricted WikiQA leaderboard. Unjudged cross-question answers may be relevant.

BGE-small-en-v1.5 is frozen. Its recommended retrieval instruction is added to questions only. The router is trained from relevance labels; no test labels are used to fit partitions, train the router, or select checkpoints. No universal transfer or advantage over full encoder fine-tuning is established.
